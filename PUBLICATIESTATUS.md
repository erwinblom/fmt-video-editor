# Publicatiestatus FMT Video Editor

## 0.2.0-preview.1 — Mac, Windows en Linux

De nieuwe bronuitgave biedt installatie- en startbestanden voor alle drie systemen. De zelfstandige basis bestaat uit opname importeren, handmatig monteren, ondertitels, thumbnails en lokale MP4-export. Bekijk [de platformcontrole](PLATFORM.md) voor het exacte bewijs.

Deze uitgave bevat geen persoonlijke interviews, accounts, modelgewichten of gebundelde runtimes. Eigen code valt onder MIT; de bestaande merk- en assetvoorwaarden blijven gelden. De leesmij-afbeelding is een toegestaan praktijkvoorbeeld en valt buiten de MIT-codelicentie.

Niet geclaimd: een kant-en-klare ondertekende native installer, een gebruikerstest met een beginner, alle Linux-distributies/Windows-versies, de kwaliteit van echte spraakherkenning of de optionele model-/cloudroutes. De automatische proeven gebruiken fictieve media.

`npm run source:check` controleert het exacte gedownloade bronpakket. `npm run candidate:check` controleert de repository en geschiedenis op uitgesloten gegevens. `npm run release:check` blijft de strengere poort voor een toekomstige stabiele volledige uitgave; deze versie blijft bewust een preview.

[Historische controles](docs/PUBLICATIE-HISTORIE.md) zijn bewaard als geschiedenis en vervangen het actuele platformbewijs niet.
